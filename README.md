# Becoming Workspace

A privacy-first personal workspace. The published site contains only generic interface code and starts with zero personal records.

## Privacy

- Records are stored only in the visitor's browser using `localStorage`.
- The app has no account, analytics, advertising, remote database, or telemetry.
- Its Content Security Policy disables outbound network connections.
- Use **Data → Export JSON** before clearing browser data or moving devices.

## Hosting

This repository is designed for GitHub Pages. Publish from the `main` branch and repository root.
